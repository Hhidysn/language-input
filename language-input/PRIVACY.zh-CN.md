# Language Input v0.1 隐私说明

## 默认行为

- 本地 GlossPack 离线工作，不发送网络请求。
- 远端缺词查询默认关闭；没有同时设置环境变量并打开方案中的 `远译` 开关时，不会创建远端请求。
- API key 只从服务进程环境变量读取，不写入 Rime 配置或远端缓存。

## 远端开启后发送什么

每次后台请求最多包含当前候选页中 9 个本地缺词、目标语言和模型名。远端服务运营方仍可能按其政策记录请求、IP、账户和计费信息；启用前应阅读所选服务的隐私与数据保留条款。

正常输入中的成功结果会写入 `%APPDATA%\Rime\language_input\remote_cache_v1.json`。缓存不包含 API key，但包含曾查询的候选词及释义；可在退出小狼毫服务后删除该文件以清空缓存。

## 敏感控件保护

TSF 路径检查 Windows InputScope，包括密码、私密、数字密码、数字 PIN、字母数字 PIN 与 PIN 设置范围；传统 IMM32 路径检查标准 `Edit`/`RichEdit` 的密码样式和密码字符。

进入敏感范围时，当前会话会立即：

- 隐藏候选释义；
- 停止并禁止朗读；
- 撤销尚未发送的远端任务，丢弃已发请求的迟到结果；
- 禁止读取或写入远端缓存；
- 禁止读取、更新或删除用户词典条目。

失去焦点和尚未完成输入范围识别的 TSF 会话按敏感状态处理。系统主词典仍可生成普通中文候选，这不属于用户学习数据。

没有输入法能够替应用正确标注所有自绘密码控件。若某个程序既不暴露 Windows InputScope，也不使用标准密码控件样式，v0.1 可能无法识别；不要在不可信或行为异常的密码界面中使用第三方输入法，应切换到系统英文键盘。

## 日志与测试数据

Release 构建不会主动把候选释义或 API key写入产品日志。验收脚本只在仓库的 `.cache\tests` 下创建隔离的临时用户词典，并且安装数据目录不允许包含 `*.userdb*`。
