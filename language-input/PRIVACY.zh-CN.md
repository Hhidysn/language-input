# Language Input v0.2 隐私说明

## 默认行为

- 固定 GlossPack 和本地 AI 都在电脑上离线运行；输入时不会下载模型，也不会把候选发送到互联网。
- AI 语言包只能由用户通过管理入口显式选择并导入，导入前会校验包与包内文件。
- 本地 Host 仅监听随机的 `127.0.0.1` 端口，使用当前进程随机生成的 64 字符令牌；令牌不写入配置、缓存或日志。
- Host 不记录候选内容，随小狼毫服务退出，并在 10 分钟没有合格请求后自行退出。
- 只有用户显式设置 `LANGUAGE_INPUT_REMOTE_ENABLED=1`，才会改用兼容 API。

## 本地保存什么

导入的模型位于 `<RimeUserDir>\language_input\models`。AI 成功结果写入 `<RimeUserDir>\language_input\ai_cache_v2.json`，按模型和目标语言隔离。缓存包含曾查询的普通候选词及其释义，不包含令牌或 API key。

默认 `<RimeUserDir>` 为 `%APPDATA%\Rime`，也可能是用户在小狼毫安装选项中指定的目录。退出小狼毫服务后，可以删除 `ai_cache_v2.json` 清空 AI 缓存；模型包需要由用户单独删除或替换。

固定词典模式读取安装目录中的英文 GlossPack，不创建 AI 缓存。AI 模式不读取固定 GlossPack 作为回退。

## 可选兼容 API

显式启用兼容 API 后，每次后台请求最多包含当前候选页的 9 个候选文字、目标语言和模型名。API key 只从服务进程环境变量读取，不写入 Rime 配置或缓存。远端服务运营方仍可能按其政策记录请求、IP、账户和计费信息。

兼容 API 默认仅允许 HTTPS，禁止重定向。明文 HTTP 需要单独显式启用，只应用于受控的本机开发测试。

## 敏感控件保护

TSF 路径检查 Windows InputScope，包括密码、私密、数字密码、数字 PIN、字母数字 PIN 与 PIN 设置范围；传统 IMM32 路径检查标准 `Edit`/`RichEdit` 的密码样式和密码字符。

进入敏感范围、失去焦点或尚未完成输入范围识别时，当前会话会立即：

- 隐藏候选译注；
- 停止并禁止朗读；
- 不启动本地 Host，不创建新的本地或远端请求；
- 撤销尚未发送的任务，丢弃已开始任务的迟到结果；
- 禁止读取或写入 AI 缓存；
- 禁止读取、更新或删除用户词典条目。

敏感状态不会把候选词、译注或朗读内容写入产品日志。系统主词典仍可生成普通中文候选，这不属于用户学习数据。

没有输入法能够替应用正确标注所有自绘密码控件。若某个程序既不暴露 Windows InputScope，也不使用标准密码控件样式，v0.2 可能无法识别；不要在不可信或行为异常的密码界面中使用第三方输入法，应切换到系统英文键盘。

## 日志与测试数据

Release 构建不会主动把候选、译注、Host 令牌或 API key 写入产品日志。验收脚本只在仓库的 `.cache\tests` 下创建隔离的临时用户词典，并且安装数据目录不允许包含 `*.userdb*`。
